# Operations Command Center

مركز قيادة عمليات تفاعلي باللغة العربية، مصمم بهوية حكومية سعودية حديثة.

- عرض عام دون تسجيل دخول.
- التحرير والحفظ المباشر بعد تسجيل الدخول بالحساب المخوّل.
- تقويم تفاعلي بمهام ممتدة، تفاصيل يومية، فلاتر، وتنبيهات تعارض.
- متابعة زمنية بحالات وألوان، لوحات تشغيلية، وتقارير وزيارات مترابطة.
- مزامنة مشتركة عبر Supabase مع سياسات RLS.
- وضع عرض شرائح وملخص أسبوعي قابل للطباعة.

## التشغيل

الموقع ملف ثابت واحد `index.html` ويُنشر عبر GitHub Pages. مخطط قاعدة البيانات محفوظ في `supabase/migrations`.
