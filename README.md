# Operations Command Center

مركز قيادة عمليات تفاعلي باللغة العربية، مصمم بهوية حكومية سعودية حديثة.

- عرض عام دون تسجيل دخول.
- التحرير والحفظ المباشر بعد تسجيل الدخول بالحساب المخوّل.
- تقويم تفاعلي بعروض يومية وشهرية وسنوية، مهام ممتدة، فلاتر، وتنبيهات تعارض.
- متابعة زمنية بحالات وألوان، لوحات تشغيلية، وتقارير وزيارات مترابطة.
- مزامنة بيانات منظّمة حسب النطاق عبر Supabase مع نسخ احتياطية وتعارضات إصدار آمنة.
- دمج الأسماء المكررة مع حفظ السجلات المؤرشفة وإعادة ربط المهام والزيارات والتقويم.
- صفحة محمية لـ«رصيد المشاركين 2026» تشمل المؤشرات والرسم الأسبوعي والفلاتر والمصدر الأصلي والصورة المرجعية، وتُحمّل بياناتها فقط بعد التحقق من الصلاحية.
- وضع عرض شرائح وملخص أسبوعي قابل للطباعة.

## التشغيل

الموقع ملف ثابت واحد `index.html` ويُنشر عبر GitHub Pages، مع تخزين البيانات التشغيلية والملفات الخاصة في Supabase.
